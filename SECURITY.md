# Security Policy

## Supported Versions

Security fixes are released for the latest published version of `winuvloop`.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing
`aviadr1@gmail.com`.

Include:

- affected version
- operating system and Python version
- reproduction steps
- whether the issue appears in `winuvloop`, `uvloop`, or `winloop`

If the vulnerability is in an upstream backend, report it to the appropriate
project as well:

- `uvloop`: <https://github.com/MagicStack/uvloop>
- `winloop`: <https://github.com/Vizonex/Winloop>
